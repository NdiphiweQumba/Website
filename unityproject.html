My Game Projects

Photon Unity Network

A real-time multiplayer game using Photon, where players can create rooms, join others, and interact within a shared environment. All players can see each other’s actions in real-time, enhancing the multiplayer experience. This project showcases the integration of Photon’s networking solutions for seamless multiplayer functionality and synchronized gameplay..

Multiplayer Game

A real-time multiplayer experience built with Unity and Photon Networking for fast interaction and gameplay.

AI-Driven Systems

A simple car simulation featuring hardcoded AI vehicles using Unity’s WheelColliders. The cars navigate a track, autonomously stopping and driving as required. This project demonstrates basic AI behavior, physics, and collision detection, showcasing the ability to simulate realistic car movements within Unity.
