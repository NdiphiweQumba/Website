Machine Learning (python, node js, C#, UnityEngine)

The app, built in Unity, uses the phone camera to capture an image and sends it via Node.js to a Python-based machine learning backend. The ML model compares the image with trained data to find the closest match, returning its name and image—similar to Google’s reverse image search. It demonstrates real-time integration between Unity, Node.js, and Python for intelligent visual recognition.
